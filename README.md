# 🪵 DANE DESIGN — Luxury Scandinavian Furniture Store

**Live Site:** [View Project](https://muralikrishna-mahanthi.github.io/dane-furniture/)  
**Built With:** HTML5 · CSS3 · Vanilla JavaScript
**Type:** UI/UX Design & Frontend Prototype

> *"Celebrating the intersection of Scandinavian heritage and mid-century modern utility."*

A fully responsive **UI/UX prototype** of a premium Scandinavian furniture brand — designed and built from scratch to demonstrate high-end eCommerce design skills. This is a static frontend project focused entirely on visual design, layout, and user experience — not a functional eCommerce application.

The goal was to capture the aesthetic language of iconic Nordic design houses through thoughtful typography, editorial layouts, and refined interactions.

# Project Scope

> This is a **UI/UX prototype only** — a static frontend design exercise.  
> There is no backend, no real cart/checkout, no database, and no dynamic functionality.  
> All content (products, prices, categories) is hardcoded for design demonstration purposes.

# Design Highlights

- **Hero Section** — Full-screen editorial layout with bold serif headline (*"The Nordic Living Room"*), dual CTA buttons, and immersive lifestyle photography
- **Category Grid** — 4-column visual browsing layout across Sofas, Lounge Chairs, Dining, and Lighting with hover states
- **New Arrivals Carousel** — Horizontally scrollable product slider with stock badges, material callouts, and pricing UI
- **Material Personalizer** — Static interactive UI simulating a timber selector (Aged Teak, White Oak, Smoked Walnut, Ash Wood) with mood descriptors
- **Minimal Navigation** — Clean top nav with category links and icon placeholders (search, account, cart)
- **Typography-First Design** — Serif + sans-serif font pairing inspired by editorial magazines like *Kinfolk*
- **Atelier Footer** — City credits (Copenhagen / Stockholm / London) with structured link layout
